# Security / 安全问题

This is an early source release. There is no security certification or guaranteed response SLA.

Please do not publish API tokens, real recordings, identifiable transcripts, database dumps, or exploitable details in a public issue. Use the repository's private vulnerability reporting option if it is available. Otherwise, open a minimal issue asking for a private reporting channel without including sensitive details or an exploit.

If a token has been exposed, revoke or rotate it at its issuer. Deleting a file or Git commit does not revoke a credential and cannot remove copies already downloaded.
