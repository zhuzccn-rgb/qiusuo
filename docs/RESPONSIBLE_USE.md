# Responsible use / 使用边界

Qiusuo is a study tool. The MIT license grants rights to the software, not to any content captured or processed with it. The confirmations help users make deliberate choices; the app cannot verify permissions or certify that a use is lawful.

求索是一款学习工具。MIT 许可证授权的是软件，不是被录下或处理的内容。应用里的确认用于提醒和明确选择，不能核验授权，也不构成法律认证。

## Before recording / 开录之前

Obtain the permissions required by your institution, instructor, participants, and applicable rules. OS microphone access is a separate device permission. If you rely on an accommodation, follow its particular terms rather than treating it as general recording or sharing permission.

确认学校、老师、参与者及适用规则要求的许可。系统麦克风权限与录音许可是两回事。通过 accommodation 录音时，也要遵守具体获批范围。

**Berkeley example, checked 2026-10-23:** the campus policy requires advance written instructor consent for ordinary classroom recordings, limits their use, and requires written consent for distribution. Approved DSP accommodations provide a distinct route with personal-study and disclosure restrictions. See the actual [campus recording policy](https://oercs.berkeley.edu/policies/campus-policy-library/course-note-taking-and-materials) and [DSP guidance](https://dsp.berkeley.edu/students/accommodations-policy-and-guidance).

**伯克利示例（2026-10-23 核对）：**普通课堂录音需要老师提前书面许可，使用和传播也受限制；DSP 批准的录音有独立条件。请以以上原文和你实际获批的范围为准。

## Before AI processing / 交给 AI 之前

Confirm that your permission covers this processing and destination. Review the endpoint, provider, gateway forwarding, retention, and any tools enabled on an agent backend. A local URL can still forward content to a cloud provider. Remove names and personal details where appropriate. Use a plain completion backend without tools if you do not need an agent.

确认授权覆盖这次处理和接收方。检查接口、网关转发、留存政策和 Agent 工具权限；本机 URL 也可能转发到云端。适当去除姓名及个人信息，不需要工具时优先使用普通对话服务。

## Before sharing / 分享之前

Check recording, transcript, slide, and generated-note permissions independently. An export confirmation does not create sharing rights. Publicly accessible materials can still have copyright and reuse restrictions. Do not submit course content, private conversations, access tokens, or identifiable student information to this project's issues or pull requests.

分别确认录音、转写、课件和生成笔记的分享权限。导出确认不会产生分享权；公开可访问也不代表可任意再发布。请勿在本项目 issue 或 PR 上传课程材料、私人谈话、密钥或可识别学生的信息。

## Scope / 范围

The project is independent and is not affiliated with or endorsed by UC Berkeley, Apple, or any model provider. Policies can change and requirements differ across settings. Consult the relevant institution or a qualified adviser when your particular use remains unclear.

本项目独立开发，未经 UC Berkeley、Apple 或模型服务商背书。规则会变化，各场景要求也不同；具体用途仍有疑问时，向相关机构或专业人士确认。
